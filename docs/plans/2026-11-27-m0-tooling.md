# M0 Repository Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hardened Electron + React + TypeScript app that opens a window with the product name on the Lagoon page colour, plus lint, type check, unit tests, end-to-end smoke test, native module smoke test, unsigned directory build and Windows CI, all as npm scripts.

**Architecture:** electron-vite builds three targets from `src/main`, `src/preload` and `src/renderer`; `src/shared` holds pure code used by more than one target. Security lives in two small, unit-tested modules in `src/main` (window options, web-contents hardening and the CSP string), and the e2e suite asserts the same properties at runtime. A Vite plugin turns `themes/lagoon/tokens.json` into a generated CSS file of custom properties that `index.html` links; the pure token logic is in `src/shared/tokens.ts`.

**Tech Stack:** Electron 45, electron-vite 6, Vite 8, React 19, TypeScript 6.0 (strict), ESLint 10 with typescript-eslint and React hooks rules, Prettier 3, Vitest 5, Playwright 1.65 (`_electron`), node-pty 1.1, better-sqlite3 13, electron-builder 26, GitHub Actions on `windows-latest`, gitleaks.

**Spec:** `docs/specs/2026-11-27-m0-tooling-design.md` (parent: `docs/specs/2026-11-26-orchtopus-product-design.md`, sections 3, 6, 7). Token rules: `DESIGN.md` sections 4 and 11.

### Native modules on Windows and in CI

- Both native modules are Node-API (ABI-stable) and ship win32-x64 prebuilds. `npm ci` compiles nothing on Windows x64, locally or on `windows-latest`, and the binaries load in Electron 45 without `@electron/rebuild`. Even a source build with node-gyp against Node headers produces a Node-API binary that loads in Electron.
- electron-builder is set to `npmRebuild: false` so packaging never triggers a source build.
- If a prebuild is missing, node-gyp builds from source. That needs Python, the Visual Studio C++ workload and, for node-pty, the Spectre-mitigated libraries (error `MSB8040`). The `windows-latest` image has the C++ workload. Whether it has the Spectre libraries is not confirmed, so a source build in CI is the main risk.
- `node:sqlite` (the spec's fallback): Node 24.22.3, the Node inside Electron 45, has `node:sqlite` without a flag (unflagged since Node 22.13). Electron's own docs do not say whether Electron exposes it, so `npm run smoke:native` prints an `INFO node:sqlite` line with the result.

## Global Constraints

Copied from the spec and `CLAUDE.md`. They apply to every task.

- Windows 10 and 11, x64. Node.js 24 for development.
- Electron app with electron-vite, TypeScript in strict mode, React for the renderer.
- Source layout: `src/main`, `src/preload`, `src/renderer`, `src/shared`.
- Security defaults from the first commit: context isolation on, sandbox on, no Node integration in the renderer, a preload that exposes nothing yet, a strict Content Security Policy, navigation and new windows denied, no remote content.
- Components use design tokens only (no hard-coded colours, spacing or fonts).
- `themes/lagoon/tokens.json` is the source (taken from `docs/design/reference/lagoon.tokens.json`). Every theme defines every non-scene token in both modes; `scene.*` is optional (`DESIGN.md` section 11).
- Package manager: npm.
- Public repository rules apply: generic names only, no secrets. CI needs no secrets.
- GitHub Actions are pinned to a commit hash or a major version tag of well-known actions only.
- The workflow only calls npm scripts (`npm ci`, `npm run check`, `npm run e2e`, `npm run smoke:native`, `npm run audit`), plus gitleaks.
- The SQLite binding is chosen by what builds cleanly for the current Electron on Windows: `better-sqlite3` first; if it does not build, `node:sqlite`. The choice and the reason go into `docs/progress.md`.
- Non-goals: terminal, sessions, local API, state store, any real UI component; installer, code signing, auto-update; UI libraries from `DESIGN.md`; a GitLab CI file.
- Anti-goals: a check that passes without testing anything; CI that is green while the app cannot start; security defaults that are switched off "for now".
- Everything in the repo is English. Conventional Commits, one commit per task. Demo names only (`acme-app`, `report-export`, ...).
- `package.json` has no `"type"` field. Main and preload are emitted as CommonJS, which a sandboxed preload requires. Config files written in JavaScript use `.mjs`; plain `.js` files are CommonJS.

import lagoonJson from '../../themes/lagoon/tokens.json';
import { buildThemeCss, missingTokens, parseTheme, tokenValue, type ThemeTokens } from './tokens';

const lagoon = parseTheme(lagoonJson);

function withTokens(mode: 'light' | 'dark', tokens: Record<string, string>): ThemeTokens {
  return { ...lagoon, [mode]: tokens };
}

function without(map: Readonly<Record<string, string>>, token: string): Record<string, string> {
  return Object.fromEntries(Object.entries(map).filter(([name]) => name !== token));
}

describe('parseTheme', () => {
  it('reads the Lagoon theme', () => {
    expect(lagoon.name).toBe('lagoon');
    expect(lagoon.version).toBe('1.0.0');
  });

  it('rejects input that is not a theme', () => {
    expect(() => parseTheme(null)).toThrow('Theme must be an object');
    expect(() => parseTheme({ ...lagoonJson, name: 'Acme App' })).toThrow('"name"');
    expect(() => parseTheme({ ...lagoonJson, dark: undefined })).toThrow('"dark"');
    expect(() => parseTheme({ ...lagoonJson, light: { 'surface.page': 1 } })).toThrow(
      'Token "surface.page" in light must be a string',
    );
  });
});

describe('missingTokens', () => {
  it('finds every non-scene Lagoon token in both modes', () => {
    expect(missingTokens(lagoon)).toEqual({ light: [], dark: [] });
  });

  it('allows scene tokens to differ between modes', () => {
    expect(Object.hasOwn(lagoon.light, 'scene.sky-top')).toBe(true);
    expect(Object.hasOwn(lagoon.dark, 'scene.sky-top')).toBe(false);
  });

  it('reports a token that is missing in one mode', () => {
    const theme = withTokens('dark', without(lagoon.dark, 'text.primary'));
    expect(missingTokens(theme)).toEqual({ light: [], dark: ['text.primary'] });
  });
});

describe('tokenValue', () => {
  it('returns the value for a mode', () => {
    expect(tokenValue(lagoon, 'light', 'surface.page')).toBe('#e3e7e5');
    expect(tokenValue(lagoon, 'dark', 'surface.page')).toBe('#0a0f17');
  });

  it('throws for an unknown token', () => {
    expect(() => tokenValue(lagoon, 'light', 'surface.unknown')).toThrow(
      'Unknown token "surface.unknown" in light',
    );
  });
});

describe('buildThemeCss', () => {
  const css = buildThemeCss(lagoon);
  const [lightPart = '', darkPart = ''] = css.split('@media (prefers-color-scheme: dark)');
  const declarations = (part: string) => part.match(/^\s+--[a-z0-9-]+: .+;$/gm) ?? [];

  it('writes light tokens on :root and dark tokens in a dark media query', () => {
    expect(lightPart).toContain(':root {');
    expect(lightPart).toContain('  --surface-page: #e3e7e5;');
    expect(lightPart).toContain('  --text-primary: #17212a;');
    expect(darkPart).toContain('    --surface-page: #0a0f17;');
    expect(darkPart).toContain('    --text-primary: #e6ecf3;');
  });

  it('writes one declaration per token', () => {
    expect(declarations(lightPart)).toHaveLength(Object.keys(lagoon.light).length);
    expect(declarations(darkPart)).toHaveLength(Object.keys(lagoon.dark).length);
  });

  it('refuses an incomplete theme', () => {
    const theme = withTokens('dark', without(lagoon.dark, 'text.primary'));
    expect(() => buildThemeCss(theme)).toThrow('Theme "lagoon" misses tokens: dark: text.primary');
  });

  it.each(['#fff; } body { display: none', '#fff\n', '   ', 'red /* x */', '<b>'])(
    'refuses the unsafe value %j',
    (value) => {
      const theme = withTokens('light', { ...lagoon.light, 'surface.page': value });
      expect(() => buildThemeCss(theme)).toThrow('Token "surface.page" in light has an unsafe value');
    },
  );

  _electron as electron,
  expect,
  test,
  type ElectronApplication,
  type Page,
} from '@playwright/test';

type Mode = 'light' | 'dark';
const tokens = JSON.parse(readFileSync('themes/lagoon/tokens.json', 'utf8')) as Record<
  Mode,
  Record<string, string>
>;

function rgb(mode: Mode, token: string): string {
  const hex = tokens[mode][token];
  if (hex === undefined) throw new Error(`Unknown token ${token}`);
  const channels = [1, 3, 5].map((start) => Number.parseInt(hex.slice(start, start + 2), 16));
  return `rgb(${channels.join(', ')})`;
}

function launchEnv(): Record<string, string> {
  const blocked = new Set(['ELECTRON_RUN_AS_NODE', 'ELECTRON_RENDERER_URL']);
  return Object.fromEntries(
    Object.entries(process.env).filter(
      (entry): entry is [string, string] => entry[1] !== undefined && !blocked.has(entry[0]),
    ),
  );
}

let app: ElectronApplication;
let page: Page;
const consoleErrors: string[] = [];

test.describe.configure({ mode: 'serial' });

test.beforeAll(async () => {
  const executablePath = process.env['E2E_EXECUTABLE'];
  app = await electron.launch(
    executablePath
      ? { executablePath, env: launchEnv(), timeout: 60_000 }
      : { args: ['.'], env: launchEnv(), timeout: 60_000 },
  );
  page = await app.firstWindow();
  page.on('console', (message) => {
    if (message.type() === 'error') consoleErrors.push(message.text());
  });
  page.on('pageerror', (error) => consoleErrors.push(error.message));
  await page.reload();
  await page.waitForLoadState('load');
});

test.afterAll(async () => {
  await app.close();
});

test('starts without console errors', () => {
  expect(consoleErrors).toEqual([]);
});

test('opens one window titled Orchtopus that shows the name', async () => {
  await expect(page).toHaveTitle('Orchtopus');
  await expect(page.getByRole('heading', { level: 1, name: 'Orchtopus' })).toBeVisible();
  const titles = await app.evaluate(({ BrowserWindow }) =>
    BrowserWindow.getAllWindows().map((window) => window.getTitle()),
  );
  expect(titles).toEqual(['Orchtopus']);
});

for (const mode of ['light', 'dark'] as const) {
  test(`paints surface.page and text.primary in ${mode} mode`, async () => {
    await app.evaluate(({ nativeTheme }, source) => {
      nativeTheme.themeSource = source;
    }, mode);
    await expect
      .poll(() => page.evaluate(() => getComputedStyle(document.body).backgroundColor))
      .toBe(rgb(mode, 'surface.page'));
    await expect
      .poll(() =>
        page.evaluate(() => {
          const heading = document.querySelector('h1');
          return heading ? getComputedStyle(heading).color : null;
        }),
      )
      .toBe(rgb(mode, 'text.primary'));
  });
}

test('renderer has no Node.js access and the preload exposes nothing', async () => {
  const globals = await page.evaluate(() => {
    const scope = globalThis as unknown as Record<string, unknown>;
    return {
      require: typeof scope['require'],
      process: typeof scope['process'],
      module: typeof scope['module'],
      exposed: Object.keys(scope).filter((key) => /electron|ipc/i.test(key)),
    };
  });
  expect(globals).toEqual({
    require: 'undefined',
    process: 'undefined',
    module: 'undefined',
    exposed: [],
  });
});

test('web preferences are hardened at runtime', async () => {
  const preferences = await app.evaluate(({ BrowserWindow }) => {
    const last = BrowserWindow.getAllWindows()[0]?.webContents.getLastWebPreferences();
    return last
      ? {
          contextIsolation: last.contextIsolation,
          sandbox: last.sandbox,
          nodeIntegration: last.nodeIntegration,
          webviewTag: last.webviewTag,
        }
      : null;
  });
  expect(preferences).toEqual({
    contextIsolation: true,
    sandbox: true,
    nodeIntegration: false,
    webviewTag: false,
  });
});

test('content security policy blocks inline scripts', async () => {
  const ran = await page.evaluate(() => {
    const script = document.createElement('script');
    script.textContent = 'globalThis.cspProbe = true';
    document.head.append(script);
    return (globalThis as unknown as Record<string, unknown>)['cspProbe'] === true;
  });
  expect(ran).toBe(false);
});

test('new windows and navigation are denied', async () => {
  expect(await page.evaluate(() => window.open('https://example.com/') !== null)).toBe(false);
  const before = page.url();
  await page.evaluate(() => {
    window.location.href = 'https://example.com/';
  });
  await page.waitForTimeout(1_000);
  expect(page.url()).toBe(before);
  expect(await app.evaluate(({ BrowserWindow }) => BrowserWindow.getAllWindows().length)).toBe(1);

- [ ] **Step 2: Write the script `scripts/smoke-native.js` (CommonJS)**

Behaviour, in this order:
1. Guard: if `process.versions.electron` is undefined or `process.type !== 'browser'`, print `FAIL runtime: not in the Electron main process (run it with npm run smoke:native; ELECTRON_RUN_AS_NODE must not be set)` to stderr and `process.exit(1)`. This happens before `require('electron')`, which returns only a path under plain Node.
2. `const { app } = require('electron')`. Start a 30-second timer that prints `FAIL timeout: native smoke did not finish in 30 s` and calls `app.exit(1)`.
3. After `app.whenReady()`, print `INFO runtime: electron <versions.electron>, node <versions.node>, modules <versions.modules>`.
4. `better-sqlite3`: `new Database(':memory:')` and `prepare('select sqlite_version() as version').get()`. PASS if `version` is a non-empty string (detail `sqlite <version>`). Any throw is FAIL with the error message.
5. `node:sqlite`: `require('node:sqlite').DatabaseSync` with the same query. Print `INFO node:sqlite: available, sqlite <version>` or `INFO node:sqlite: not available (<message>)`. This line never changes the exit code.
6. `node-pty`: `spawn('cmd.exe', ['/d', '/c', 'set /a 12345+54321'], { name: 'xterm-256color', cols: 80, rows: 24, cwd: process.cwd(), env: process.env })`. Collect `onData` output. In `onExit`, wait 500 ms (ConPTY can deliver the last output after the exit event), then PASS if `exitCode === 0` and the output contains `66666` (the command text does not contain the result, so an echoed command cannot pass). Detail: `exit <code>, result <seen|missing>`. A throw on `require` or `spawn` is FAIL.
7. Print `native smoke: all checks passed` or `native smoke: <n> check(s) failed`, then `app.exit(failed ? 1 : 0)`.

## Decisions for the lead to confirm

1. **TypeScript 6.0.3, not 7.0.2.** typescript-eslint 8.74.0 supports only `<6.1.0`.
2. **No `@vitejs/plugin-react`.** JSX goes through Vite's built-in `oxc`, so there is no Fast Refresh (HMR reloads the page). This keeps `script-src 'self'` strict in dev as well.
3. **Token completeness excludes `scene.*`.** This follows `DESIGN.md` section 11 and the mode-specific scene group in the source file. The spec's wording "every token exists in both modes" cannot hold for the given source.
4. **Token CSS is generated by a Vite plugin** into the gitignored `src/renderer/generated/lagoon.css`, not committed.
5. **Native modules use their Node-API prebuilds:** no `@electron/rebuild`, `npmRebuild: false`, `signAndEditExecutable: false` for the unsigned build.
6. **CI layout:** one Windows job for the npm scripts, gitleaks in a separate `ubuntu-latest` job. `npm run audit` is `--audit-level=high` over all dependencies, dev included. CI does not run `npm run package`. The packaged app is verified locally in Task 9.
7. **Exact version pins** (`--save-exact`). React is a devDependency, because it is bundled into the renderer.
