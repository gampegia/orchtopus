# Third-party skills and tools

Orchtopus uses or recommends these external projects. Check each repository for its current licence and install command before use.

| Project | Use in Orchtopus | Licence (as noted when the concept was written) |
|---|---|---|
| [obra/superpowers](https://github.com/obra/superpowers) | Development workflow: brainstorming, plans, subagent-driven development, TDD, reviews | MIT |
| [heydamir/unslop](https://github.com/heydamir/unslop) by Damir Sokolovsky | Design pass for every UI change (E26) | CC BY 4.0 – keep the attribution |
| [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) | Output style rules for texts to the user (E32) | MIT |
| ASD-STE100 Simplified Technical English | Writing rules, applied at about 80 % (E32) | Specification by ASD; rules paraphrased, not copied |
| xterm.js, node-pty | Terminal in the app | MIT |
| GitHub CLI (`gh`), GitLab CLI (`glab`) | PR/MR, pipelines, reviews (E30) | MIT |
| Lucide icons (used in the mockups) | Icon set | ISC |
